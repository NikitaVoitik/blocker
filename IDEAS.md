# Product ideas

Punishment Mode's promise: when someone blocks a distracting site, the extension holds that line and shows them what happened when they tried to cross it. Keep blocking absolute and evidence local. Daily time allowances do not fit the "no mercy" idea.

## 1. Close blocking gaps — first priority

Audit blocked sites across direct links, mobile hosts, subdomains, redirects, and browser restarts. Add regression tests for every gap found. A block should hold regardless of the route used to reach the site.

## 2. Optional commitment lock

Let someone lock a blocked site against removal through the popup for a chosen period. When that period ends, the site stays blocked; the existing removal gauntlet becomes available again. Explain plainly that Chrome still lets people disable or uninstall the extension.

## 3. Incognito protection warning

Check whether Chrome has allowed the extension to run in Incognito. If not, show a clear warning in the popup with instructions to enable it in Chrome's extension settings. Do not imply the extension can switch this on by itself.

## 4. Sharper shame report

Show repeat attempts at the same site, attempts after removing a block, and the longest clean streak. Use the existing local attempt and removal history where possible; keep the report and photos on the device.
